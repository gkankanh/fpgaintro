# Icestudio in this course

Icestudio is the visual path: you wire blocks on a canvas instead of typing
Verilog. It drives [apio](https://github.com/FPGAwars/apio), which wraps the
same yosys and nextpnr the editor path uses — so the two paths are two front
ends onto one toolchain, not two different worlds.

## Opening a lesson

Each dual-path lesson keeps its project in its own folder:

```bash
open 00-blinky/icestudio/blink.ice
open 06-spi-oled/icestudio/oled.ice
```

Or *File → Open* inside Icestudio. The board is already set to **ULX3S-85F**,
so *Build* and *Upload* work with no further setup.

## Where the projects come from

They are generated, not hand-drawn. Each lesson has a short spec next to the
`.ice` file:

```
00-blinky/icestudio/blink.json    the spec: which .v, which pins
00-blinky/icestudio/blink.ice     generated by tools/mkice.py
```

The spec names the Verilog file and binds each port to a board pin;
`tools/mkice.py` lifts the module body into an Icestudio `basic.code` block and
resolves the pin names to real ECP5 balls. So the diagram cannot drift from the
Verilog — it *is* the Verilog, laid out on a canvas.

After editing a lesson's `.v`, regenerate:

```bash
make ice          # all lessons
python3 tools/mkice.py 00-blinky/icestudio/blink.json    # just one
```

If you edit a project inside Icestudio and want to keep the change, copy it
back into the `.v` — the `.v` is the source of truth, because that is what the
testbenches and `make sim-all` run against.

## Going the other way

For a lesson with no Icestudio project, or when you want to see what the
synthesiser made of your code:

```bash
cd 07-font-rom && make graph      # -> text_top.svg
```

yosys and graphviz render your Verilog as a schematic. Worth doing on every
lesson at least once.

## `collections/`

Reusable course blocks — a debouncer, an edge detector, a UART — so later
lessons can drop in earlier work instead of re-drawing it. Empty for now;
lesson 02 is the first that will put something here.

To make Icestudio see them, set *Edit → Preferences → External collections* to
this directory. (If you already have it pointed somewhere else, your previous
setting is saved in `~/.icestudio/profile.json.bak` by this repository's setup.)

## Caveat

The `.ice` files here are generated from Icestudio's documented project schema
and its own ULX3S-85F board definition, but they have not been opened in the
GUI as part of an automated test — there is no headless Icestudio to test with.
If one fails to load, the spec and `tools/mkice.py` are both short and readable;
please open an issue with what it said.
